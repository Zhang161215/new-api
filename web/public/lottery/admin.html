    兑换码

    查库存和发放，或导入兑换页下载的 txt。文件名如 0.5.txt、1.txt、3.txt、10.txt 会自动对应额度奖。缺货时转盘会暂停，补货后自动恢复。

    兑换码 奖项 额度 状态 发放给 时间

    录入兑换码

    支持兑换页下载的 txt：一行一个码。也可直接粘贴。中奖只发码，用户到充值页自行兑换。

    次数规则

    抽奖开关只控制能不能抽。群播报开关只控制中奖后是否推到 QQ 群，关掉期间抽中的不会补发。

    用户成功支付 1 笔充值 → +N 次；点击抽奖 → −1 次。关掉抽奖后不能抽，但充值仍会送次数。关掉播报后群里不再推中奖消息，期间抽中的也不会补发。模拟支付只补次数，不改账户额度。

    查询用户次数

    用用户 ID 或用户名查找。留空点查询会列出已有抽奖次数的用户。点一行填入右侧补发。

    用户 ID 用户名 剩余次数 已抽次数 累计额度
    点查询查看用户次数

    手动补发次数

    按用户 ID 补发抽奖次数。只加次数，不改账户额度。记录会出现在「次数流水」里，类型为手动补发。

    礼包发放

    按时间范围内的充值 / 消费筛选人员，确认后再发抽奖次数。同一时间批次同一用户只入账一次。发放后用户打开控制台会弹礼包提醒，关掉后记在账号上，换设备也不会再弹。打开本页不会自动发放。
